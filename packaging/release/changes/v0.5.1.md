v0.5.1 包含 v0.5.0 的全部内容；已安装用户可整组升级，无需重分区或重刷根镜像。

### 修复

- 触控服务重启后触摸稳定恢复，不再出现重启后触摸持续失效。
- 快速反复注销再登录不再造成系统整体停顿。

内核 ABI：`piano28`；内核提交：`5ed69822d95a564e9743c27c446107363ec6abd1`。

### 已知限制

- 浏览器视频目前为软件解码。
- 拔下 OTG 设备后，直接插入的 OTG 转接头可能不被识别；插拔一次充电器或电脑线，或改用扩展坞即可。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、USB-C 外接显示、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.5.1/ubuntu/README.md)。

---

v0.5.1 includes everything in v0.5.0. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Fixed

- Touch recovers reliably after the touch service restarts; touch no longer stays dead after such a restart.
- Repeated quick logout and login cycles no longer stall the system.

Kernel ABI: `piano28`; kernel commit: `5ed69822d95a564e9743c27c446107363ec6abd1`.

### Known limitations

- Browser video currently uses software decoding.
- After an OTG device is unplugged, a plain OTG adapter plugged in next may not be detected; plug a charger or computer cable in and out once, or use a dock.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, USB-C external display, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.5.1/ubuntu/README.md).
