v0.2.0 是第一个完整走过全新安装验收的版本，相比 v0.1.0-preview：

- 显示：原生 DSI 显示驱动取代固件帧缓冲，3200×2136 / 144 Hz，背光可调，关屏/亮屏正常。
- 触控：关屏再亮屏后触控自动恢复（触控驱动跟随面板电源序列）。
- 图形：Adreno 830 GPU 加速覆盖桌面和 snap 应用（含 Firefox）。
- 视频：Iris 硬件解码器可用（1080p H.264 已验证）。
- Wi-Fi：5 GHz 80 MHz 连接稳定。
- 音频：内置麦克风录音；扬声器播放（音量上限受限，无扬声器保护）。
- 传感器：加速度、陀螺、光感、距离可用；拆下键盘后自动旋转。
- 键盘：磁吸键盘按键可用；检测键盘吸附状态。
- 电源：电量、电压、电流和温度可读；充电状态只读。
- 双系统：Ubuntu 内、Android 内（KernelSU 模块）和主机 Fastboot 三种切换方式；切换前干净关机。
- 安装：全新安装流程已在测试机完整验证；新增 AI 辅助安装提示词和升级文档。
- 发布：附件改为 boot / tools / packages 三个压缩包加根镜像分卷。

---

v0.2.0 is the first release that went through a complete fresh-install acceptance. Compared with v0.1.0-preview:

- Display: the native DSI driver replaces the firmware framebuffer; 3200×2136 at 144 Hz, backlight control, screen off/on.
- Touch: touch recovers after the screen is turned off and on again (the touch driver follows the panel power sequence).
- Graphics: Adreno 830 GPU acceleration for the desktop and for snap applications including Firefox.
- Video: the Iris hardware decoder works (1080p H.264 verified).
- Wi-Fi: stable 5 GHz 80 MHz links.
- Audio: internal microphone recording; speaker playback (capped volume, no speaker protection).
- Sensors: accelerometer, gyroscope, light and proximity; auto-rotation with the keyboard detached.
- Keyboard: magnetic keyboard keys; keyboard attach state detection.
- Power: battery level, voltage, current and temperatures; read-only charger state.
- Dual boot: switching from Ubuntu, from Android (KernelSU module) and from the host (Fastboot); clean shutdown before switching.
- Installation: the fresh-install procedure was verified in full on the test unit; new AI-assisted installation prompt and upgrade guide.
- Release: assets are now three archives (boot, tools, packages) plus the split root image.
