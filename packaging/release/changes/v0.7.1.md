### 更新

- GPU 计算性能提升：Geekbench 6 Vulkan 约 +24%，部分计算任务接近翻倍。

### 已知限制

- Firefox 播放部分 HEVC 视频可能有轻微丢帧。AV1 使用软件解码，Chromium snap 不支持此硬解集成。
- 拔下 OTG 设备后，直接插入的 OTG 转接头可能不被识别；插拔一次充电器或电脑线，或改用扩展坞即可。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包和任务管理器 Resources 受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.7.1/ubuntu/README.md)。

---

v0.7.1 includes everything in v0.7.0. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Changes

- Improved GPU compute performance: about +24% in Geekbench 6 Vulkan, with some compute workloads nearly doubling.

Kernel unchanged (`piano40`); kernel commit: `9321086f2e22`.

### Known limitations

- Some HEVC videos may drop a small number of frames in Firefox. AV1 uses software decoding; Chromium snap is not covered by this acceleration integration.
- After an OTG device is unplugged, a plain OTG adapter plugged in next may not be detected; plug a charger or computer cable in and out once, or use a dock.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages and the Resources task manager are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.7.1/ubuntu/README.md).
