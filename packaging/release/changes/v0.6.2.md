v0.6.2 包含 v0.6.1 的全部内容；已安装用户可整组升级，无需重分区或重刷根镜像。

### 更新

- 任务管理器（Resources）能看到完整的硬件数据：CPU 温度；GPU 型号 Adreno 830、当前与最高频率、温度和占用率；每个进程的 GPU 占用；两块电池各自的温度。
- 修复偶发的开机后没有声音、传感器无数据、USB-C 不工作（需重启才恢复）：音频、充电和传感器协处理器在开机时发来的第一条握手消息不再被内核丢弃。

内核 ABI：`piano38`；内核提交：`235ab34e2a6e`。

### 已知限制

- Firefox 播放部分 HEVC 视频可能有轻微丢帧。AV1 使用软件解码，Chromium snap 不支持此硬解集成。
- 拔下 OTG 设备后，直接插入的 OTG 转接头可能不被识别；插拔一次充电器或电脑线，或改用扩展坞即可。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包和任务管理器 Resources 受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.6.2/ubuntu/README.md)。

---

v0.6.2 includes everything in v0.6.1. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Changes

- The task manager (Resources) shows complete hardware data: CPU temperature; the Adreno 830 GPU model, current and maximum frequency, temperature and utilisation; per-process GPU usage; and the temperature of each of the two batteries.
- Fixes an occasional boot without sound, sensor data or USB-C that only a reboot recovered: the kernel no longer drops the first handshake message the audio, charging and sensor coprocessor sends during boot.

Kernel ABI: `piano38`; kernel commit: `235ab34e2a6e`.

### Known limitations

- Some HEVC videos may drop a small number of frames in Firefox. AV1 uses software decoding; Chromium snap is not covered by this acceleration integration.
- After an OTG device is unplugged, a plain OTG adapter plugged in next may not be detected; plug a charger or computer cable in and out once, or use a dock.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages and the Resources task manager are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.6.2/ubuntu/README.md).
