v0.6.0 包含 v0.5.1 的全部内容；已安装用户可整组升级，无需重分区或重刷根镜像。

### 更新

- USB 主机与设备模式支持 5 Gbit/s SuperSpeed，Type-C 正反插均可；U 盘实测写约 330 MB/s、读约 390 MB/s。
- 支持 USB-C 外接显示器（DisplayPort Alt Mode）：正反插、热插拔均可，实测 4K 60 Hz，外接屏作为扩展桌面。
- 插拔电源时，按原厂方式向触控芯片通知供电状态。
- 扬声器最大音量提高。
- Firefox 支持 H.264/VP9/HEVC 硬件解码，Chrome 支持 H.264/VP9。
- 文件系统默认字符集为 UTF-8；U 盘中文文件名按 UTF-8 处理。

内核 ABI：`piano32`；内核提交：`722ec84628367aa3d1f20f64857d7a8d0166de30`。

### 已知限制

- Firefox 播放部分 HEVC 视频可能有轻微丢帧。AV1 使用软件解码，Chromium snap 不支持此硬解集成。
- 拔下 OTG 设备后，直接插入的 OTG 转接头可能不被识别；插拔一次充电器或电脑线，或改用扩展坞即可。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.6.0/ubuntu/README.md)。

---

v0.6.0 includes everything in v0.5.1. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Changes

- USB host and device modes support 5 Gbit/s SuperSpeed in both Type-C orientations; a USB stick measured about 330 MB/s write and 390 MB/s read.
- USB-C external displays (DisplayPort Alt Mode) work in both orientations and with hot-plug; tested at 4K 60 Hz as an extended desktop.
- The touch controller is notified when external power is connected or disconnected, following the stock behavior.
- The maximum speaker volume has been increased.
- Firefox supports H.264/VP9/HEVC hardware decoding; Chrome supports H.264/VP9.
- The default filesystem character set is UTF-8, including Chinese filenames on USB storage.

Kernel ABI: `piano32`; kernel commit: `722ec84628367aa3d1f20f64857d7a8d0166de30`.

### Known limitations

- Some HEVC videos may drop a small number of frames in Firefox. AV1 uses software decoding; Chromium snap is not covered by this acceleration integration.
- After an OTG device is unplugged, a plain OTG adapter plugged in next may not be detected; plug a charger or computer cable in and out once, or use a dock.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.6.0/ubuntu/README.md).
