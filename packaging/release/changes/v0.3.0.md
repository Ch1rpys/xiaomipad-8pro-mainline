v0.3.0 面向已安装 v0.2.0 的用户，也提供完整安装镜像。升级不需要重分区或重刷根镜像。

### 新增

- GNOME 自带夜灯可用：50 轮开关、关屏/亮屏和睡眠恢复通过。

- 前后摄像头可出图，通过独立相机服务与 loopback 提供视频；后摄采用固定焦距。
- 开启系统待机：RTC、电源键、键盘与开盖唤醒通过，合盖不触发唤醒；保留 GNOME/logind 的默认电源键与合盖策略。
- 磁吸键盘熄屏按键唤醒、睡眠唤醒和打字可用。
- H.264、H.265、VP9 硬件解码慢消费测试各通过 150/150 帧；H.264/H.265 1080p 与 4K 硬件编码已验证。

### 修复

- 修正显示关闭顺序与双路显示时钟恢复，刷新率切换及关屏/亮屏通过。
- 修正充电挂起限流及恢复，避免持续报错；提高内置麦克风录音增益。
- 修复 Mesa 桌面与 snap 图形兼容问题；未配置颜色描述的内屏自动软关联发行版标准 sRGB，不覆盖用户配置。
- 集成显示、睡眠、蓝牙和视频验收工具；相机原始节点由相机服务独占，避免桌面媒体服务争用。

### 已知问题

- 切换到 120 或 60 Hz 后触控可能失效，需切回 144/90 Hz；建议保持 144 或 90 Hz。
- 蓝牙偶发重连成功但数据不通。
- AV1 硬件解码可能丢失首帧；播放器是否自动使用硬解仍取决于应用。
- 后摄没有自动对焦，近景可能偏虚；颜色与白平衡仍需调校。
- 手写笔、USB 主机、USB-C 外接显示和指纹仍不支持。
- 无扬声器保护，保持默认音量上限；无可恢复的交换区，不支持休眠到磁盘。硬件时钟不可写，开机后联网校时。

升级时请一起安装发布包中的内核、设备包和相机包，保留旧内核与回退镜像组。

---

v0.3.0 supports upgrading an existing v0.2.0 installation without repartitioning or reflashing the root image.

### Added

- GNOME Night Light: 50 on/off cycles, screen off/on and suspend restoration verified.

- Front and rear camera capture through the camera service and loopback; fixed rear focus.
- System suspend with RTC, power-button, keyboard and cover-open wake. Closing the cover does not wake the device. GNOME/logind default power and lid actions apply.
- Keyboard typing and key wake with the screen off and from suspend.
- H.264/H.265/VP9 slow-consumer hardware decoding: 150/150 frames each. H.264/H.265 encoding verified at 1080p and 4K.

### Fixed

- Display shutdown order and bonded-clock restoration; refresh switching and screen off/on verified.
- Charging current-limit restoration across suspend; higher internal microphone recording gain.
- Mesa desktop and snap compatibility. An unconfigured panel receives a soft association with the distribution sRGB profile, preserving user choices.
- Integrated display, suspend, Bluetooth and video acceptance tools; raw camera nodes reserved for the camera service.

### Known issues

- Touch can fail after switching to 120 or 60 Hz; return to 144/90 Hz. Prefer 144 or 90 Hz.
- Bluetooth occasionally reconnects without working data.
- AV1 hardware decoding can lose its first frame; automatic player use of hardware decoding varies.
- No rear autofocus; nearby subjects can be blurry, and color/white balance tuning remains limited.
- Stylus, USB host, USB-C external display and fingerprint remain unsupported.
- No speaker protection: retain the default volume cap. No disk hibernation without resumable swap; the unwritable hardware clock requires network time after boot.

Install the kernel, device and camera packages together; retain the previous kernel and rollback boot set.
