v0.3.1 面向已安装 v0.3.0 的用户，也提供完整安装镜像；升级无需重分区或重刷根镜像。

### 修复

- 修复熄屏、锁屏和待机时的一帧花屏：面板仍扫描时不再提前复位共享显示控制器。42 轮关屏/亮屏无接口欠载，两半屏图像 CRC 通过。
- 集成社区的音频就绪与设备移除、传感器等待可冻结、DSI PHY 接口时钟运行时电源管理修复；恢复后音频与双摄出图通过。
- 触控驱动容忍一次已恢复的 SPI 读取错误（仅编译与 KUnit 验证，真机未复现该故障）；触控服务发生流错误后自动重启，重启恢复已真机验证。

### 变更

- 内核更新为 Linux 7.2.10-piano25；已在现有根系统上 RAM 启动验收，六种显示模式、120/144 Hz 关屏/亮屏 CRC 和两次 s2idle 通过。
- 相机服务自动启动，使双摄可在相机应用中使用；后摄仍为固定焦距。相机改为输出 BGRx 以绕过 GTK/NV12 预览条纹，Snapshot 预览已在真机确认正常；转换使用 NEON，每帧 1.9 ms，后摄预览时相机服务约占一个 CPU 核的 19%。如需原 NV12 输出，可在 `/etc/piano/camera.conf` 写入 `PIANO_CAMERA_OUTPUT=nv12`。
- 设置 → 电源可配置电源键动作，默认待机；保留用户已有设置。

### 已知问题

- 切换到 120 或 60 Hz 后触控可能失效，需切回 144/90 Hz；建议保持 144 或 90 Hz。
- 蓝牙偶发重连成功但数据不通。
- AV1 硬件解码可能丢失首帧；播放器是否自动使用硬解仍取决于应用。
- 后摄没有自动对焦，近景可能偏虚；颜色与白平衡仍需调校。
- 手写笔、USB 主机、USB-C 外接显示和指纹仍不支持。
- 无扬声器保护，保持默认音量上限；无可恢复的交换区，不支持休眠到磁盘。硬件时钟不可写，开机后联网校时。
- GTK 应用在此 GPU 上显示硬解码/NV12 视频时有条纹，GNOME 视频播放器也受影响；相机预览使用 BGRx 绕过。
- 罕见的触控控制器重启后，触控可能需要约一秒恢复。
- 其他设备看到的本机蓝牙类别为“未分类”：为在设置中提供电源键选项，机型标识改为可变形（convertible），BlueZ 尚未映射该机型。

请一起安装全部发布软件包，保留旧内核及回退镜像组。

v0.3.1 upgrades an existing v0.3.0 installation and also provides full installation images. No repartitioning or root-image flash is needed for an upgrade.

### Fixed

- Removed the single-frame garbled flash on screen-off, lock and suspend: the shared display controller is no longer reset while the panel is scanning. All 42 DPMS cycles had zero interface underruns and CRC-verified pictures on both halves.
- Imported community fixes for audio readiness versus device removal, freezable sensor waiters and DSI PHY interface-clock runtime PM; audio after resume and both camera streams passed.
- The touch driver tolerates one recovered SPI read error (compile and KUnit coverage only; the fault was not reproduced on hardware). The touch service automatically restarts after a stream error; restart recovery was verified on the tablet.

### Changed

- Linux 7.2.10-piano25: RAM boot on the installed root passed all six display modes, 120/144 Hz DPMS CRC checks and two s2idle cycles.
- The camera service starts automatically so both cameras are available in apps; rear focus remains fixed. The camera now publishes BGRx to work around GTK/NV12 preview stripes; the Snapshot preview was verified on the tablet. The NEON conversion takes 1.9 ms per frame, and the camera service uses about 19 % of one CPU core during a rear-camera preview. Write `PIANO_CAMERA_OUTPUT=nv12` to `/etc/piano/camera.conf` to restore NV12 output.
- The power-button action is configurable in Settings → Power, defaulting to suspend and preserving existing personal choices.

### Known issues

- Touch can fail after switching to 120 or 60 Hz; return to 144/90 Hz. Prefer 144 or 90 Hz.
- Bluetooth occasionally reconnects without working data.
- AV1 hardware decoding can lose its first frame; automatic player use of hardware decoding varies.
- No rear autofocus; nearby subjects can be blurry, and color/white balance tuning remains limited.
- Stylus, USB host, USB-C external display and fingerprint remain unsupported.
- No speaker protection: retain the default volume cap. No disk hibernation without resumable swap; the unwritable hardware clock requires network time after boot.
- GTK applications render hardware-decoded/NV12 video with stripes on this GPU; GNOME video players are affected; camera preview uses a BGRx workaround.
- Touch may need a second to recover after a rare touch-controller restart.
- Other devices see this tablet's Bluetooth class as uncategorized: the chassis is reported as convertible so that Settings offers the power-button option, and BlueZ does not map that chassis yet.

Install every release package together; retain the previous kernel and rollback boot set.
