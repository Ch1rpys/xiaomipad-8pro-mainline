v0.7.0 包含 v0.6.2 的全部内容；已安装用户可整组升级，无需重分区或重刷根镜像。

### 更新

- 机身温度：新增 11 路板载温度读数，通过系统标准的 thermal 和 hwmon 接口提供，名称沿用原厂固件（xo、msm、flash、wifi、display、backlight、conn、conn2、battery、quiet、charger1）。
- 任务管理器新增“温度”页：按设备分组列出全部温度传感器，显示当前值，展开可看历史曲线，单位跟随任务管理器设置。
- 内置存储启用 UFS 多队列：每个 CPU 核有自己的请求队列和中断，并发读写不再挤在同一个队列里。

内核 ABI：`piano40`；内核提交：`9321086f2e22`。

### 已知限制

- Firefox 播放部分 HEVC 视频可能有轻微丢帧。AV1 使用软件解码，Chromium snap 不支持此硬解集成。
- 拔下 OTG 设备后，直接插入的 OTG 转接头可能不被识别；插拔一次充电器或电脑线，或改用扩展坞即可。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包和任务管理器 Resources 受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.7.0/ubuntu/README.md)。

---

v0.7.0 includes everything in v0.6.2. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Changes

- Board temperatures: 11 more on-board temperature readings through the standard thermal and hwmon interfaces, named as in the stock firmware (xo, msm, flash, wifi, display, backlight, conn, conn2, battery, quiet, charger1).
- The task manager has a new Temperature page: every temperature sensor grouped by device, with the current value and an expandable history graph, in the unit chosen in the task manager's settings.
- Internal storage uses UFS multi-circular queues: each CPU core has its own request queue and interrupt, so concurrent reads and writes no longer share a single queue.

Kernel ABI: `piano40`; kernel commit: `9321086f2e22`.

### Known limitations

- Some HEVC videos may drop a small number of frames in Firefox. AV1 uses software decoding; Chromium snap is not covered by this acceleration integration.
- After an OTG device is unplugged, a plain OTG adapter plugged in next may not be detected; plug a charger or computer cable in and out once, or use a dock.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages and the Resources task manager are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.7.0/ubuntu/README.md).
