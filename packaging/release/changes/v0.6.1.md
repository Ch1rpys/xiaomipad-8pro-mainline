v0.6.1 包含 v0.6.0 的全部内容；已安装用户可整组升级，无需重分区或重刷根镜像。

### 更新

- 自动识别屏型（CSOT 或 BOE），加载对应的触控固件、触控方向和屏幕初始化。
- 传感器服务现在会保存 DSP 对传感器 registry 的更新。
- 若传感器 registry 反复导致 ADSP 崩溃（表现为没有声音、传感器无数据），启动时自动把旧状态移到一旁保留，并恢复默认状态。
- 安装说明补充 256 GB 机型的分区方法；推荐导入本机传感器标定。

内核 ABI：`piano33`；内核提交：`55a703614e1577b9db117c935ec0e64634263aed`。

### 已知限制

- Firefox 播放部分 HEVC 视频可能有轻微丢帧。AV1 使用软件解码，Chromium snap 不支持此硬解集成。
- 拔下 OTG 设备后，直接插入的 OTG 转接头可能不被识别；插拔一次充电器或电脑线，或改用扩展坞即可。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.6.1/ubuntu/README.md)。

---

v0.6.1 includes everything in v0.6.0. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Changes

- The panel type (CSOT or BOE) is detected automatically and loads its own touch firmware, touch orientation and display initialization.
- The sensor service now keeps the sensor registry updates written by the DSP.
- If the sensor registry keeps crashing the ADSP (no sound, no sensor data), it is moved aside and kept at boot, and the default state is restored.
- The installation guide covers the partition layout of the 256 GB model and recommends importing the tablet's own sensor calibration.

Kernel ABI: `piano33`; kernel commit: `55a703614e1577b9db117c935ec0e64634263aed`.

### Known limitations

- Some HEVC videos may drop a small number of frames in Firefox. AV1 uses software decoding; Chromium snap is not covered by this acceleration integration.
- After an OTG device is unplugged, a plain OTG adapter plugged in next may not be detected; plug a charger or computer cable in and out once, or use a dock.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.6.1/ubuntu/README.md).
