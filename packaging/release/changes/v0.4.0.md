v0.4.0 包含 v0.3.2 的全部修复，面向已安装 v0.3.2 的用户，也提供完整安装镜像；升级无需重分区或重刷根镜像。

### 修复

- 切换显示刷新率到 120 或 60 Hz 后，触控不再失效。
- 修复亮屏后触控偶尔持续失效的问题。
- 触控改为在后台重启，亮屏约快 0.3 秒。
- GTK 应用使用默认的 Vulkan 渲染器显示 NV12 图像（相机预览、软件解码的视频帧）时不再出现斜条纹：集成上游 Mesa Adreno 830 Vulkan 驱动修复。

### 变更

- 相机恢复默认输出 NV12，降低 CPU 占用：后摄预览时相机服务约占一个 CPU 核的 4%，Snapshot 约 17%（BGRx 分别约 19% 和 32%）。如需 BGRx，可在 `/etc/piano/camera.conf` 写入 `PIANO_CAMERA_OUTPUT=bgrx`；NEON 转换路径保留。
- 内核更新为 Linux 7.2.10-piano26，加入触控异步启动；其余组件与 v0.3.2 相同。

### 已知问题

- 蓝牙偶发重连成功但数据不通。
- AV1 硬件解码可能丢失首帧；播放器是否自动使用硬解仍取决于应用。
- 后摄没有自动对焦，近景可能偏虚；颜色与白平衡仍需调校。
- 手写笔、USB 主机、USB-C 外接显示和指纹仍不支持。
- 无扬声器保护，保持默认音量上限；无可恢复的交换区，不支持休眠到磁盘。硬件时钟不可写，开机后联网校时。
- SPI 错误导致触控失效时，可重启触控服务恢复。
- 其他设备看到的本机蓝牙类别为“未分类”：为在设置中提供电源键选项，机型标识改为可变形（convertible），BlueZ 尚未映射该机型。
- 极少数情况下音频与相机会同时停止工作，重启可恢复（已观察到一次，原因调查中）。

请一起安装全部发布软件包，重启以启用新内核、刷新 snap 图形提供程序并让应用加载新驱动；保留旧内核及回退镜像组。

v0.4.0 includes all v0.3.2 fixes, upgrades an existing v0.3.2 installation and also provides full installation images. No repartitioning or root-image flash is needed for an upgrade.

### Fixed

- Touch no longer stops working after switching the display to 120 or 60 Hz.
- Touch no longer occasionally stays unresponsive after the screen turns on.
- The screen lights up about 0.3 seconds faster because touch restarts in the background.
- GTK applications using the default Vulkan renderer no longer draw NV12 images (camera previews and software-decoded video frames) with diagonal stripes, thanks to an upstream Mesa Adreno 830 Vulkan driver fix.

### Changed

- The camera publishes NV12 again to reduce CPU use: during a rear-camera preview, camerad uses about 4 % of one core and Snapshot about 17 % (versus 19 % and 32 % with BGRx). Write `PIANO_CAMERA_OUTPUT=bgrx` to `/etc/piano/camera.conf` to restore BGRx; the NEON conversion path remains available.
- The kernel is updated to Linux 7.2.10-piano26 with asynchronous touch startup; all other components are unchanged from v0.3.2.

### Known issues

- Bluetooth occasionally reconnects without working data.
- AV1 hardware decoding can lose its first frame; automatic player use of hardware decoding varies.
- No rear autofocus; nearby subjects can be blurry, and color/white balance tuning remains limited.
- Stylus, USB host, USB-C external display and fingerprint remain unsupported.
- No speaker protection: retain the default volume cap. No disk hibernation without resumable swap; the unwritable hardware clock requires network time after boot.
- Restart the touch service to recover touch after an SPI error.
- Other devices see this tablet's Bluetooth class as uncategorized: the chassis is reported as convertible so that Settings offers the power-button option, and BlueZ does not map that chassis yet.
- In rare cases audio and the camera can stop working at the same time; a reboot recovers (seen once, under investigation).

Install every release package together and reboot to activate the new kernel, refresh the snap graphics provider and let applications pick up the new driver; retain the previous kernel and rollback boot set.
