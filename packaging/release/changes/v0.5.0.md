v0.5.0 包含 v0.4.0 的全部修复；已安装用户可整组升级，无需重分区或重刷根镜像。

### 新增

- USB 主机 / OTG：支持扩展坞、U 盘、键盘和鼠标，以及连接供电扩展坞时边充边用。
- 电源键默认锁屏；屏幕熄灭后再次短按唤醒锁屏界面。已有个人设置保留，可在“设置 → 电源”中选择“锁定屏幕”。
- GNOME 提供节能、平衡、性能三档，默认平衡；可从快速设置或“设置 → 电源”切换。
- 默认安装 Showtime 及 GStreamer 播放依赖，包含软件解码回退；自动使用硬解取决于播放器。

内核 ABI：`piano27`；内核提交：`<v0.5.0 kernel commit>`。

### 已知限制

- 浏览器视频目前为软件解码。
- 蓝牙偶发需要重新连接才能恢复数据或音频。
- 后摄为固定焦距，近景可能偏虚，颜色调校仍有限。

手写笔、指纹、USB-C 外接显示、休眠到磁盘及硬件时钟写入仍不支持。保留默认扬声器音量上限，开机后联网校时。

请整组安装全部发布软件包并重启，保留旧内核及回退镜像组。电源键的四个 Ubuntu 补丁包受版本锁定保护，其安全更新需随配套重建包交付；维护流程见 [Ubuntu 集成](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.5.0/ubuntu/README.md)。

v0.5.0 includes all v0.4.0 fixes. Existing installations can upgrade the complete package set without repartitioning or flashing a new root image.

### Added

- USB host / OTG support for docks, USB storage, keyboards and mice, including charging while using a powered dock.
- The power button locks the screen by default. Press it again with the screen off to wake the lock screen. Existing personal settings are preserved; choose Lock Screen in Settings → Power.
- Power Saver, Balanced and Performance modes in GNOME, with Balanced as the default. Switch modes in quick settings or Settings → Power.
- Showtime and its GStreamer playback dependencies are installed by default, including software decoding fallback; automatic hardware decoding depends on the player.

Kernel ABI: `piano27`; kernel commit: `<v0.5.0 kernel commit>`.

### Known limitations

- Browser video currently uses software decoding.
- Bluetooth occasionally needs reconnecting before data or audio works again.
- The rear camera has fixed focus; nearby subjects may be blurry and color tuning is limited.

Stylus, fingerprint, USB-C external display, disk hibernation and hardware clock writes remain unsupported. Keep the default speaker volume cap and connect to the network to set the clock after boot.

Install every release package together and reboot; retain the previous kernel and rollback boot set. The four Ubuntu power-button packages are version-pinned, so their security updates require matched rebuilt packages; see [Ubuntu integration](https://github.com/yzddmr6/xiaomipad-8pro-mainline/blob/v0.5.0/ubuntu/README.md).
