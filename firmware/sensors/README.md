# Stock piano sensor configuration

Static ODM/vendor configuration from OS3.0.303.0.WPYCNXM. Each source path and
SHA256 is in `source.json`. This is not the persist registry. ROM default
`fac_cal` entries are generic; unit-specific persist calibration is excluded.

Distributed by the owner's 2026-10-12 decision under the same policy as the
other stock firmware: no redistribution licence has been established; remove
upon rightsholder request. These files are not licensed under the repository's
MIT licence. See `device/sensors/README.zh-CN.md` for private calibration staging.
